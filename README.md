# -loan-portfolio-analytics-dashboard
Power BI dashboard analyzing a 42,000+ row loan dataset.
## About the Project
This project analyzes a loan portfolio of 42,000+ records to understand how many loan applications are approved, how many loans default, and how much money is still outstanding.

**Problem:** [The bank needs to determine which customer and loan characteristics are associated with higher default risk.
]

**Approach:**
1. Cleaned the raw data in Python (Pandas).
2. Built a star-schema data model in Power BI.
3. Wrote DAX measures for Approval Rate, Default Rate and Outstanding Amount.
4. Designed a 4-page interactive dashboard.
